# M&S SPORT DATA

Sitio web estático para presentar la propuesta académica y un prototipo visual de indicadores para el fútbol formativo del C.D. Héctor Cárdenas, en Cali.

## Ejecutar localmente

No requiere instalación de dependencias ni compilación:

1. Abre `index.html` directamente en un navegador; o
2. Abre la carpeta en Visual Studio Code y ejecútala con una extensión de servidor estático, como Live Server.

## Estructura

- `index.html`: contenido y secciones de la página.
- `styles.css`: estilos adaptables a escritorio y móvil.
- `app.js`: filtros, datos sintéticos y renderizado de los gráficos del prototipo.
- `assets/ms-sport-data-logo.jpg`: logotipo proporcionado para el encabezado y el pie de página.

## Prototipo de indicadores

El panel permite filtrar por categoría, entrenador y tipo de indicador. Los registros del tablero son **datos sintéticos de demostración**; no son información del club ni resultados de investigación. Las alertas son ejemplos de apoyo a la conversación y no constituyen diagnósticos ni recomendaciones automatizadas.

La arquitectura y las fases describen una propuesta conceptual; el sitio no se conecta a una base de datos ni implementa un sistema de gestión.

## Referencias conceptuales

La página incluye autores de referencia para orientar el marco conceptual. Contrasta sus datos bibliográficos con la bibliografía aprobada del anteproyecto antes de entregar o publicar el trabajo.
